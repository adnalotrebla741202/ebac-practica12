<h1>Práctica #12 de mi curso de FrontEnd de EBAC</h1>
<h2>Descripción del proyecto</h2>
Este proyecto es una maqueta web de una tienda de comida poblana con una interfaz limpia, diseño responsivo y enfoque en la presentación de productos. Incluye una sección de productos, un banner promocional y una vista del carrito de compras, aunque aún no cuenta con funcionalidad dinámica.
<h2>Tecnologías utilizadas</h2>
<ul>
  <li>Este proyecto está hecho con <b>HTML5</b> y <b>CSS</b>.</li>
  <li>Este proyecto es una página web para una tienda de comida típica poblana.</li>
  <li>Cuenta con una estructura HTML semántica.</li>
  <li>El encabezado <b>&lt;header&gt;</b> contiene tres elementos principales que son un icono de menú (el cual servirá para navegar en móviles), el logotipo de la tienda y el icono del carrito de compras.</li>
  <li>El <b>&lt;main&gt;</b> contiene tres partes que son el banner, los productos y el carrito de compras.</li>
  <li>El banner definido por la clase <b>.banner</b> cuenta con una imagen de fondo con texto, un título y un subtítulo.</li>
  <li>Los productos definidos por la clase <b>.products</b> muestran una cuadricula <b>grid</b> con tarjetas de productos y cada tarjeta incluye imagen del producto, nombre del platillo y precio.</li>
   <li>El carrito de compras definido por la clase <b>.cart</b> es una caja lateral con productos añadidos y está diseñada para mostrar la imagen del producto, el nombre del producto, el precio y el icono para eliminar el producto.</li> 
  <li>El carrito no tiene funcionalidad dinámica aún (es decir, no agrega ni elimina productos mediante JavaScript).</li>
  <li>El proyecto tiene un diseño con una tipografía moderna con Google Fonts.</li>
  <li>El proyecto tiene un diseño responsivo, con media queries para adaptar el diseño a Tabletas y Móviles.</li>
  <li>El proyecto cuenta con un estilo limpio y profesional con fondos oscuros para el header, colores blancos y grises para el contenido e imágenes de productos bien posicionadas.</li>
</ul>
<h2>Instrucciones de instalación y uso</h2>
<ul>
  <li>Para usar este código hay que ir a la pestaña Code | Download ZIP.</li>
  <li>Descomprimir el archivo zipeado, entrar a la carpeta creada y buscar el archivo <b>index.html</b>.</li>
  <li>Una vez localizado el archivo <b>index.html</b> le damos doble click a dicho archivo y se nos abrirá el proyecto HTML en nuestro navegador de Internet predeterminado.</li>
  <li>Este proyecto es un web site de antojitos poblanos.</li>
  <li>Cuando cambiamos el diseño de tamaño los elementos que conforman el diseño web se ajustan de tal manera que se adaptan al tamaño del dispositivo de despliegue y de esta manera el usuario puede seguir viendo el contenido completo del sitio web sin que falte o se desborde algún elemento.</li>
</ul>
